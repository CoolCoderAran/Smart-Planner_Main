# Contributing to Smart Planner 🎓

Thank you for your interest in **Smart Planner**! 

## 🔒 Code Contribution Status

Because this repository is currently submitted for review and evaluation (including the **Congressional App Challenge**), **direct code contributions, pull requests (PRs), and external branch merges are currently closed**.

To preserve build integrity and submission consistency, pull requests will not be merged at this time.

---

## 🐛 How You Can Help

While code contributions are paused, feedback and issue reports are still welcome! If you encounter a bug, notice unexpected behavior, or have ideas for future enhancements, please open an issue on GitHub.

### 1. Reporting Bugs
If you find a bug, please [open a new issue](https://github.com/CoolCoderAran/Smart-Planner_Main/issues) with the following details:
- **Description**: A clear summary of what happened.
- **Steps to Reproduce**: Detailed steps showing how to trigger the issue.
- **Expected Behavior**: What should have happened instead.
- **Environment**: Your browser and operating system.

### 2. Suggesting Features
Have an idea to make Smart Planner better? Feel free to submit a feature request under GitHub Issues detailing:
- The problem your feature solves.
- How you envision the feature working.

---

Thank you for testing and exploring Smart Planner!
